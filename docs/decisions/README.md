## Belum diputuskan
- Nama merek dan lisensi final (implikasi GPLv3 ERPNext/HRMS perlu diverifikasi).
- Rancangan sisa Sesi 3 (dialog tanggal dan tombol "Tarik Sekarang", penjadwalan tarikan rutin) dan Sesi 4 (agen Windows, endpoint konfigurasi agen, penyimpanan token di PC agen); format Impor File menunggu contoh berkas ekspor.
- Field `device_record_no` (ditunda, K-59).
- Mesin `WP 221` (kelas masalah kode 6001): jalur apa yang dipakai.
- Perilaku mesin saat jejak transaksi penuh (perlu dicek di manual MB460).
- Arti status `Terkirim` pada Raw Log (tidak ada kode yang mengisinya; mengunci edit dan ikut dihitung).
- Aturan lembur lanjutan (pengali, hari libur) dan aturan khusus Security (istirahat Security Pagi dan Malam sementara 0).
- `overtime_min_minutes` berfungsi sebagai lembur minimal sekaligus kelipatan; dipisah menjadi dua field bila aturannya berubah.
- Pengaruh "Dipinjam untuk Grup" pada laporan, lembur, dan insentif (K-39 hanya mencatat).
- `HRIS Shift`: apakah shift nonaktif boleh bila masih dipakai grup, rotasi, atau assignment. Perubahan jam shift tidak merusak working hour yang sudah disimpan (K-35), tetapi tanggal lampau yang dihitung ulang mengikuti jam shift terbaru.
- Tumpang tindih jendela antar shift (shift malam hari ini dan shift pagi esok): satu punch bisa dipakai dua hari; menunggu data nyata.
- Konfirmasi asumsi: nilai `review_status` dan `overtime_type`, detik punch dibuang, hari tidak wajib tanpa punch = Libur, toleransi telat dan pulang cepat 0 pada semua shift.
- Cuti dan izin; insentif; komponen gaji spesifik.
- Akuntansi gaji: jurnal otomatis ke ERPNext atau cukup laporan.
- Apakah `hrms` tetap `required_apps` jika hanya Employee yang dipakai.
- Pemetaan `verify_mode` (jari/wajah) dan arti "no akun" dan "no induk" di Raw Log.
- Merek/model mesin untuk uji template wajah; prioritas 3 bulan.
- Satu atau dua bench untuk production; nasib site uji lama.
- Navigasi: Sidebar modul dan Dock (usulan), bukan Desktop Icon.
