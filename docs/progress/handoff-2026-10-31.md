## 5. Isu terbuka dan risiko yang belum terverifikasi

| # | Hal | Catatan |
|---|---|---|
| 1 | `pull_status` mensyaratkan hak write pada HRIS Device | HR Admin mungkin melihat riwayat tetapi status terkini ditolak. Perbaikan satu baris bila terbukti; jangan ubah tanpa konfirmasi Efendy |
| 2 | Konsol memuat daftar mesin lewat `frappe.client.get_list` | Mengikuti hak baca HRIS Device; belum diverifikasi untuk HR Admin. Bila kosong, buat fungsi server khusus |
| 3 | Penyebab counter bersama pada `format:{kode}-...` | Kesimpulan dari perilaku; belum dibaca di `frappe/model/naming.py` |
| 4 | Nomor Pull Run mulai dari 0003 saat uji | Kosmetik, penyebab tidak diketahui |
| 5 | `frappe.enqueue` meneruskan `run_name` sebagai kwarg | Terbukti jalan (Pull Run tercatat) |
| 6 | Teks "Tidak ada Raw Log di mesin dan rentang ini" membingungkan | Ganti ke "untuk mesin dan rentang ini" saat perapian |
| 7 | Push ke GitHub meminta username/password | Pakai Personal Access Token atau SSH key; jangan tempel token di chat |
| 8 | Memori proyek | Penyimpanan ke memori diblokir di chat sesi ini karena memakai konektor. Simpan ulang dari chat baru tanpa konektor aktif |

Satu hal yang perlu diverifikasi: apakah HRIS HR Admin benar bisa membuka Konsol Mesin dan Status. Cara: login sebagai akun berole itu, atau cek Role Permission Manager di Desk untuk HRIS Device dan HRIS Pull Run.
